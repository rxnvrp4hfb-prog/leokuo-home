# Leo Kuo Contact Page

Static contact page for `leokuo.com`.

## Edit Contact Info

Open `index.html` and update the values near the top:

```js
window.LEO_CONTACT = {
  line: { href: "https://line.me/ti/p/GGU72198eK", value: "leo20613" },
  instagram: { href: "https://instagram.com/_yo7.24", value: "@_yo7.24" },
  phone: { href: "tel:+886你的電話", value: "你的電話" }
};
```

## Preview

Open `index.html` directly in a browser, or serve this folder with any static host.
