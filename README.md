# Leo Kuo Contact Page

Static contact page for `leokuo.com`.

## Edit Contact Info

Open `public/index.html` and update the contact links.

## Change Profile Photo

Upload or replace `public/avatar.jpg`. No HTML changes are required. When the
file is absent, the page falls back to the `LK` initials.

## Preview

Open `public/index.html` directly in a browser, or serve the `public` folder with any static host.
